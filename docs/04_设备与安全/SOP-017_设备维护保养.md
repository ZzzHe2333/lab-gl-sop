# SOP-017 设备维护保养

> **公开草案 V0.1｜未审核、未批准、不得直接作为现场作业依据。**
> 本文件为脱敏的通用管理模板。所有专有配方、设备操作边界、危险化学品细节、人员与原始数据应另存于受控内部系统。

## 1. 目的与范围

建立可追溯的预防维护、故障维修和复机管理。适用于经组织授权、符合现行法律法规和设备制造商要求的相关实验室活动；不替代具体工艺卡、设备说明书、SDS 与应急预案。

## 2. 角色与职责

设备管理员、授权维修人员、设备使用人按岗位授权和职责分离原则分工；实际操作者填写原始记录，复核或审批人员独立签署。组织未确定的岗位由内部文件另行指定，公开文件不含个人名单。

## 3. 作业前提

- 已取得适用的受控方案、工艺卡或检验方法版本，并确认当前有效。
- 人员能力、场所安全、仪器状态、原辅材料和必要的应急资源符合要求。
- 核查批次、设备、样品及记录编号对应关系；发现不明确事项时暂停开展相关步骤。

## 4. 标准程序

1. 根据制造商手册和实际使用风险建立设备清单、保养周期与备件规则。
2. 维护前确认停机、能量隔离、降温泄压及作业许可要求已落实。
3. 按受控工单开展清洁、润滑、检查、易损件更换与必要的功能试验。
4. 记录更换件型号、批次、维修人、日期、故障原因及异常情况。
5. 涉及关键安全部件、控制逻辑或测量链的维修，须重新验证并必要时走变更程序。
6. 由使用人与管理人员共同确认复机条件，解除停用标识并更新台账。
7. 定期分析故障频率、停机原因及保养完成率，更新预防计划。

## 5. 关键控制与放行

- [ ] 禁止带压带电违规维护
- [ ] 维修后必做功能验证
- [ ] 关键改变应触发变更管理
- [ ] 实际记录已由经授权人员复核，相关异常、偏差及变更均有处置结论。
- [ ] 涉及定量阈值、保存时限或安全联锁时，只引用已批准的内部标准，禁止根据本示例自行推定。

## 6. 异常及安全要求

出现危及人员安全、设备完整性或数据可信度的情形，应立即停止相关操作并执行经批准的现场应急或隔离程序，报告授权责任人；不得绕过防护措施、擅自恢复运行或删除异常记录。按 SOP-006 和 SOP-016 处理调查与整改。

## 7. 配套记录与关联文件

- 记录表单：FM-013（详见 `forms/` 目录；具体字段可按受控场景扩展）。
- 通用关联：SOP-004 实验记录与数据管理、SOP-018 文件与记录控制、SOP-020 变更管理。
