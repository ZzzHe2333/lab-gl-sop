# SOP-017 设备维护保养

> **公开草案 V0.2｜未审核、未批准、不得直接作为现场作业依据。**
> 本文件为脱敏的通用管理模板。所有专有配方、设备操作边界、危险化学品细节、人员与原始数据应另存于受控内部系统。

## 1. 目的与范围

建立可追溯的预防维护、故障维修和复机管理。适用于经组织授权、符合现行法律法规和设备制造商要求的相关实验室活动；不替代具体工艺卡、设备说明书、SDS 与应急预案。

## 2. 角色与职责

设备管理员、授权维修人员、设备使用人按岗位授权和职责分离原则分工；实际操作者填写原始记录，复核或审批人员独立签署。组织未确定的岗位由内部文件另行指定，公开文件不含个人名单。

## 3. 作业前提

- 已取得适用的受控方案、工艺卡或检验方法版本，并确认当前有效。
- 人员能力、场所安全、仪器状态、原辅材料和必要的应急资源符合要求。
- 核查批次、设备、样品及记录编号对应关系；发现不明确事项时暂停开展相关步骤。

## 4. 标准程序

1. 根据制造商手册和实际使用风险建立设备清单、保养周期与备件规则。
2. 维护前确认停机、能量隔离、降温泄压及作业许可要求已落实。
3. 按受控工单开展清洁、润滑、检查、易损件更换与必要的功能试验。
4. 记录更换件型号、批次、维修人、日期、故障原因及异常情况。
5. 涉及关键安全部件、控制逻辑或测量链的维修，须重新验证并必要时走变更程序。
6. 由使用人与管理人员共同确认复机条件，解除停用标识并更新台账。
7. 定期分析故障频率、停机原因及保养完成率，更新预防计划。

## 5. 关键控制与放行

- [ ] 禁止带压带电违规维护
- [ ] 维修后必做功能验证
- [ ] 关键改变应触发变更管理
- [ ] 实际记录已由经授权人员复核，相关异常、偏差及变更均有处置结论。
- [ ] 涉及定量阈值、保存时限或安全联锁时，只引用已批准的内部标准，禁止根据本示例自行推定。

## 6. 异常及安全要求

出现危及人员安全、设备完整性或数据可信度的情形，应立即停止相关操作并执行经批准的现场应急或隔离程序，报告授权责任人；不得绕过防护措施、擅自恢复运行或删除异常记录。按 SOP-006 和 SOP-016 处理调查与整改。

## 8. 可执行分步检查（参考公开实验室管理经验）

下表为流程检查模板。所有具体容差、安全阈值、计量标准、周期与法定要求必须由适用的受控资料确认。

| 关口 | 执行要点 | 通过或输出证据 | 不满足时 |
| --- | --- | --- | --- |
| 资产资料 | 登记设备用途、制造商要求、维护手册和安全保护 | 设备档案可追溯 | 资料不全暂停高危维护 |
| 维护计划 | 按频次、故障历史、环境和风险制定备件与维护计划 | 责任、周期和延期机制明确 | 关键保养逾期评估停用 |
| 维修许可 | 确认停机、断电、隔离储压/热源和危险物料 | 必要的专业资质及监护具备 | 许可不全不开工 |
| 实施维护 | 按厂家手册检查密封、阀件、旋转件、传感器和控制装置 | 记录检查和更换件信息 | 异常升级专业维修 |
| 维修后验证 | 依据维修范围复核机械、电气、密闭、联锁和必要计量性能 | 有实测验收和记录 | 验证失败继续停用 |
| 复机交付 | 确认防护恢复、无遗留工具、状态牌更新、使用人接收 | 授权放行后恢复 | 不得私自解除停用 |
| 故障回顾 | 分析重复故障、计划完成率和工单质量 | 维护计划有改进依据 | 纳入CAPA/变更 |

## 9. 原始记录的最小证据链

- [ ] 维护前隔离与作业许可
- [ ] 维修工单、故障描述、更换部件
- [ ] 功能/计量再验证数据
- [ ] 复机批准和历史修订

每项任务应能串联：任务与版本 → 责任岗位和设备 → 判断依据 → 实际记录 → 异常处置 → 独立复核 → 放行或关闭。只在授权的内部系统填写真实数据。

## 10. 常见错漏及审核关注点

- **检查：**不能以保养替代校准。
- **检查：**不得随意旁路安全联锁。
- **检查：**维护异常必须评估设备使用风险。

**复核要求：** 不能把其他实验室的设备边界、药品参数或审批周期直接视为本实验室有效标准；每个审核结果均应有记录位置和处置授权。
