# SOP-011 检测仪器校准与期间核查

> **公开草案 V0.2｜未审核、未批准、不得直接作为现场作业依据。**
> 本文件为脱敏的通用管理模板。所有专有配方、设备操作边界、危险化学品细节、人员与原始数据应另存于受控内部系统。

## 1. 目的与范围

保证量测设备可追溯且在规定性能范围内使用。适用于经组织授权、符合现行法律法规和设备制造商要求的相关实验室活动；不替代具体工艺卡、设备说明书、SDS 与应急预案。

## 2. 角色与职责

设备管理员、使用人、校准/核查人员、审核人按岗位授权和职责分离原则分工；实际操作者填写原始记录，复核或审批人员独立签署。组织未确定的岗位由内部文件另行指定，公开文件不含个人名单。

## 3. 作业前提

- 已取得适用的受控方案、工艺卡或检验方法版本，并确认当前有效。
- 人员能力、场所安全、仪器状态、原辅材料和必要的应急资源符合要求。
- 核查批次、设备、样品及记录编号对应关系；发现不明确事项时暂停开展相关步骤。

## 4. 标准程序

1. 建立设备唯一编号、量程、精度、使用位置、责任人及校准状态台账。
2. 根据设备说明书、测量风险及法规确定校准周期和期间核查方案。
3. 校准前检查设备外观、状态、环境和参照标准的有效性。
4. 按受控方法实施校准或核查，记录标准值、示值、偏差、条件和判定依据。
5. 发现超差时停用并评估此前数据及报告可能受影响的范围。
6. 调整或维修后执行必要的再校准和功能验证，合格后解除停用状态。
7. 校准证书、核查记录、标签和设备台账保持一致。

## 5. 关键控制与放行

- [ ] 不得使用过期或超差设备
- [ ] 判定阈值需有溯源依据
- [ ] 超差要追溯受影响数据
- [ ] 实际记录已由经授权人员复核，相关异常、偏差及变更均有处置结论。
- [ ] 涉及定量阈值、保存时限或安全联锁时，只引用已批准的内部标准，禁止根据本示例自行推定。

## 6. 异常及安全要求

出现危及人员安全、设备完整性或数据可信度的情形，应立即停止相关操作并执行经批准的现场应急或隔离程序，报告授权责任人；不得绕过防护措施、擅自恢复运行或删除异常记录。按 SOP-006 和 SOP-016 处理调查与整改。

## 8. 送审前待确认事项

- [ ] 各设备周期
- [ ] 允许误差
- [ ] 标准器与实验室能力
- [ ] 技术负责人、安全负责人和文件批准人确认适用性、法律法规与设备制造商要求。
- [ ] 实际启用日期、适用岗位、培训与版本控制经正式批准。

## 8. 可执行分步检查（参考公开实验室管理经验）

下表为流程检查模板。所有具体容差、安全阈值、计量标准、周期与法定要求必须由适用的受控资料确认。

| 关口 | 执行要点 | 通过或输出证据 | 不满足时 |
| --- | --- | --- | --- |
| 仪器台账 | 记录用途、量程、精度、责任人与关键程度 | 资产编号与任务对应 | 资料不全不得安排关键测量 |
| 校准计划 | 按制造商、用途、稳定性和风险确定频次及校准点 | 计划有到期和负责人 | 逾期标停用 |
| 计量溯源 | 核对证书测量范围、标准器及不确定度 | 证书满足实际测量要求 | 不能只凭证书存在放行 |
| 期间核查 | 选取覆盖常用范围的检查点和控制样 | 结果和趋势有记录 | 超差或趋势异常时停用 |
| 超差回溯 | 查询最后可信核查至异常期间的全部任务 | 影响清单与复测决定齐全 | 更正已发报告 |
| 复机批准 | 维修后核查、必要时再校准并更新状态标识 | 复用由授权人员批准 | 不得无痕恢复 |

## 9. 原始记录的最小证据链

- [ ] 仪器编号、型号、量程及使用项目
- [ ] 校准和标准器证书、计量溯源链
- [ ] 核查原始值、允许误差依据和趋势
- [ ] 超差影响评估、复测及授权

每项任务应能串联：任务与版本 → 责任岗位和设备 → 判断依据 → 实际记录 → 异常处置 → 独立复核 → 放行或关闭。只在授权的内部系统填写真实数据。

## 10. 常见错漏及审核关注点

- **检查：**只有校准证书不代表每一测量结果都可溯源。
- **检查：**校准、功能维护与方法适用性是不同检查。
- **检查：**核查阈值不得随意借用其他实验室。

**复核要求：** 不能把其他实验室的设备边界、药品参数或审批周期直接视为本实验室有效标准；每个审核结果均应有记录位置和处置授权。
