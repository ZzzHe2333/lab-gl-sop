# SOP-008 过程与中控检测

> **公开草案 V0.2｜未审核、未批准、不得直接作为现场作业依据。**
> 本文件为脱敏的通用管理模板。所有专有配方、设备操作边界、危险化学品细节、人员与原始数据应另存于受控内部系统。

## 1. 目的与范围

在实验过程中为工艺决策提供可核实的测量结果。适用于经组织授权、符合现行法律法规和设备制造商要求的相关实验室活动；不替代具体工艺卡、设备说明书、SDS 与应急预案。

## 2. 角色与职责

取样人、检测员、工艺负责人按岗位授权和职责分离原则分工；实际操作者填写原始记录，复核或审批人员独立签署。组织未确定的岗位由内部文件另行指定，公开文件不含个人名单。

## 3. 作业前提

- 已取得适用的受控方案、工艺卡或检验方法版本，并确认当前有效。
- 人员能力、场所安全、仪器状态、原辅材料和必要的应急资源符合要求。
- 核查批次、设备、样品及记录编号对应关系；发现不明确事项时暂停开展相关步骤。

## 4. 标准程序

1. 依据实验计划确定取样节点、检测项目、时效和样品数量。
2. 按批准方法采样，记录取样时的运行状态及可能影响结果的因素。
3. 核对样品标签、接收状态和检测优先级，异常样品先隔离确认。
4. 检查仪器状态并进行必要的空白、对照和质量控制。
5. 保留原始曲线、照片、读数和处理算法版本，严禁只保留最终结论。
6. 将关键结果及时反馈过程负责人；对异常结果进行复核，不得直接以单次测试替代风险判断。
7. 把检测结果与对应实验节点、样品编号和处置结论关联归档。

## 5. 关键控制与放行

- [ ] 样品时间点与实验编号必须对应
- [ ] 检测方法变更应事先批准
- [ ] 异常结果须留存复测证据
- [ ] 实际记录已由经授权人员复核，相关异常、偏差及变更均有处置结论。
- [ ] 涉及定量阈值、保存时限或安全联锁时，只引用已批准的内部标准，禁止根据本示例自行推定。

## 6. 异常及安全要求

出现危及人员安全、设备完整性或数据可信度的情形，应立即停止相关操作并执行经批准的现场应急或隔离程序，报告授权责任人；不得绕过防护措施、擅自恢复运行或删除异常记录。按 SOP-006 和 SOP-016 处理调查与整改。

## 7. 配套记录与关联文件

- 记录表单：FM-007（详见 `forms/` 目录；具体字段可按受控场景扩展）。
- 通用关联：SOP-004 实验记录与数据管理、SOP-018 文件与记录控制、SOP-020 变更管理。

## 8. 送审前待确认事项

- [ ] 采样频次
- [ ] 样品稳定性
- [ ] 检测方法和控制阈值
- [ ] 技术负责人、安全负责人和文件批准人确认适用性、法律法规与设备制造商要求。
- [ ] 实际启用日期、适用岗位、培训与版本控制经正式批准。

## 8. 可执行分步检查（结合公开实验室管理经验补充）

本节是管理层面的示例流程，需按现场设备和人员授权制定内部版，不提供未验证的化学操作数值。

| 关口 | 执行要点 | 通过或输出证据 | 不满足时 |
| --- | --- | --- | --- |
| 监测计划 | 从实验目标与风险中识别需监测的过程指标、样本节点和响应时效 | 取样节点与控制决策有对应关系 | 监测计划不清不得以单次数据决定关键操作 |
| 现场取样 | 按批准的取样方法记录时间、位置、运行状态和取样者 | 样品代表性和安全操作均有依据 | 取样条件不符时停止并登记 |
| 接收识别 | 核对样品编号、数量、保存条件、取样时刻和时效 | 未超经验证的稳定时间，容器相容 | 不合格接收需评估而非擅测 |
| 方法选择 | 核对受控检测方法、仪器量程、样品预处理及适用基质 | 检测方法适用于该样品，质控可完成 | 标注方法偏离并审批 |
| 质量控制 | 按方法记录空白、重复性、标准品或控制样结果 | 质控合格方可用于过程判定 | 质控失效应复核或重新取样 |
| 结果沟通 | 明确结果值、单位、采样状态、检测时间和方法限制 | 接收人确认理解判定范围 | 紧急指标按批准的上报链执行 |
| 数据归档 | 归档原始曲线/图像、复测与过程参数链接 | 可回溯到单一运行时间点 | 缺数据列为偏差 |

## 9. 原始记录最小字段与证据链

- [ ] 过程采样计划与目标属性
- [ ] 采样时刻、操作状态、温度等内部实测信息
- [ ] 检测方法版本、仪器与质量控制
- [ ] 报告审核/反馈时间与接收人
- [ ] 异常、复测、处置决策

记录必须能串联：任务或实验编号 → 样品／设备／物料 → 方法及原始数据 → 质量复核 → 偏差及最终结论。所有实际标识与数据仅在内部受控系统填写。

## 10. 典型错漏与复核要点

- **关注：**过程数据不应脱离取样工况解释。
- **关注：**不满足稳定性要求的样品不能直接视为有效。
- **关注：**紧急反馈要保留通知记录。

**复核关口：** 对本SOP每一项关键控制，应有核验依据、记录位置、核验角色及发现问题后的处置；没有依据的定量限值不得从其他实验室直接移植。
