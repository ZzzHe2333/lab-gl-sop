# SOP-018 文件与记录控制

> **公开草案 V0.2｜未审核、未批准、不得直接作为现场作业依据。**
> 本文件为脱敏的通用管理模板。所有专有配方、设备操作边界、危险化学品细节、人员与原始数据应另存于受控内部系统。

## 1. 目的与范围

统一文件编制、审批、发放、修订、归档与废止。适用于经组织授权、符合现行法律法规和设备制造商要求的相关实验室活动；不替代具体工艺卡、设备说明书、SDS 与应急预案。

## 2. 角色与职责

文件管理员、编制人、审核人、批准人按岗位授权和职责分离原则分工；实际操作者填写原始记录，复核或审批人员独立签署。组织未确定的岗位由内部文件另行指定，公开文件不含个人名单。

## 3. 作业前提

- 已取得适用的受控方案、工艺卡或检验方法版本，并确认当前有效。
- 人员能力、场所安全、仪器状态、原辅材料和必要的应急资源符合要求。
- 核查批次、设备、样品及记录编号对应关系；发现不明确事项时暂停开展相关步骤。

## 4. 标准程序

1. 统一文件编号和版本规则，明确文件类别、密级、适用范围和拥有者。
2. 新建或修订文件须经技术、安全及管理权限相应审核，批准后才可标为有效。
3. 发布时登记生效日期、接收范围、培训要求及旧版本回收情况。
4. 现场仅使用有效受控版本，纸质复制件与电子副本应可识别状态。
5. 记录按文件目录指定保存位置、访问权限、保存期限和备份方案。
6. 对作废文件保留必要的历史记录但防止误用，涉及隐私或保密内容依法处置。
7. 公开仓库仅存放非敏感模板，不得上传真实配方、人员信息、实验原始数据或受控审批件。

## 5. 关键控制与放行

- [ ] 未经批准不得标注正式生效
- [ ] 修订要保留历史版本
- [ ] 公开与内部文件分层存储
- [ ] 实际记录已由经授权人员复核，相关异常、偏差及变更均有处置结论。
- [ ] 涉及定量阈值、保存时限或安全联锁时，只引用已批准的内部标准，禁止根据本示例自行推定。

## 6. 异常及安全要求

出现危及人员安全、设备完整性或数据可信度的情形，应立即停止相关操作并执行经批准的现场应急或隔离程序，报告授权责任人；不得绕过防护措施、擅自恢复运行或删除异常记录。按 SOP-006 和 SOP-016 处理调查与整改。

## 7. 配套记录与关联文件

- 记录表单：FM-016（详见 `forms/` 目录；具体字段可按受控场景扩展）。
- 通用关联：SOP-004 实验记录与数据管理、SOP-018 文件与记录控制、SOP-020 变更管理。
- 记录应保持真实、完整、可追溯，不在公开仓库录入实际生产或研发数据。

## 8. 送审前待确认事项

- [ ] 编号规则
- [ ] 保存期限
- [ ] 审批链与密级策略
- [ ] 技术负责人、安全负责人和文件批准人确认适用性、法律法规与设备制造商要求。
- [ ] 实际启用日期、适用岗位、培训与版本控制经正式批准。

## 8. 可执行分步检查（参考公开实验室管理经验）

下表为流程检查模板。所有具体容差、安全阈值、计量标准、周期与法定要求必须由适用的受控资料确认。

| 关口 | 执行要点 | 通过或输出证据 | 不满足时 |
| --- | --- | --- | --- |
| 文件分层 | 区分公开模板、内部规程、工艺卡、记录、检验方法和外部标准 | 密级与拥有者清楚 | 机密文件禁止公开同步 |
| 起草审查 | 核对目的、职责、引用、执行与异常步骤 | 版本号及引用有效 | 缺项保持草案 |
| 技术安全审查 | 技术复核操作可行，安全复核危险源及法规，管理复核权限 | 每条意见有关闭记录 | 未审不发布 |
| 批准发布 | 登记批准角色、生效日期、适用范围、培训与旧版状态 | 有效版本唯一 | 退回未获批草案 |
| 分发使用 | 受控发放纸电副本，并确保现场能获取有效版本 | 可查签收和借阅 | 停用过时版本 |
| 修订回收 | 变更评估并同步相关SOP、表单、培训和旧版回收 | 历史记录与现用版分开 | 不能抹去旧审批 |
| 保存与销毁 | 落实保存期限、加密访问、备份恢复及清理审批 | 数据和隐私保护有效 | 发现泄露启动安全事件 |

## 9. 原始记录的最小证据链

- [ ] 文件编号、类别、密级和拥有者
- [ ] 版本、审签与生效日期
- [ ] 发放接收/回收与修订记录
- [ ] 保存与访问控制证据

每项任务应能串联：任务与版本 → 责任岗位和设备 → 判断依据 → 实际记录 → 异常处置 → 独立复核 → 放行或关闭。只在授权的内部系统填写真实数据。

## 10. 常见错漏及审核关注点

- **检查：**GitHub版本提交不是审批。
- **检查：**公开草案不能冒充正式文件。
- **检查：**保密信息与公开模板须分离。

**复核要求：** 不能把其他实验室的设备边界、药品参数或审批周期直接视为本实验室有效标准；每个审核结果均应有记录位置和处置授权。
