# SOP-005 实验物料与样品管理

> **公开草案 V0.1｜未审核、未批准、不得直接作为现场作业依据。**
> 本文件为脱敏的通用管理模板。所有专有配方、设备操作边界、危险化学品细节、人员与原始数据应另存于受控内部系统。

## 1. 目的与范围

实现物料从领用到退库以及样品从采集到处置的全链条管理。适用于经组织授权、符合现行法律法规和设备制造商要求的相关实验室活动；不替代具体工艺卡、设备说明书、SDS 与应急预案。

## 2. 角色与职责

物料管理员、实验操作人、检测接收人按岗位授权和职责分离原则分工；实际操作者填写原始记录，复核或审批人员独立签署。组织未确定的岗位由内部文件另行指定，公开文件不含个人名单。

## 3. 作业前提

- 已取得适用的受控方案、工艺卡或检验方法版本，并确认当前有效。
- 人员能力、场所安全、仪器状态、原辅材料和必要的应急资源符合要求。
- 核查批次、设备、样品及记录编号对应关系；发现不明确事项时暂停开展相关步骤。

## 4. 标准程序

1. 新物料入库登记名称、来源、批次、数量、危害属性、储存条件和有效期，关联适用的安全资料。
2. 按相容性和储存条件分区，关键易变质物料设置监测与超期处置流程。
3. 领料时按批准清单核对物料标识、批次、有效状态和数量，记录领取与归还。
4. 取样后以唯一编号标识样品来源、采集时间、保存条件、危害警示与用途。
5. 样品在实验组、检测组及外协方之间移交时记录交接人、时间、容器状态和数量。
6. 按批准留样方案执行保留、复测、销毁与空容器处置，禁止丢弃未识别样品。
7. 盘点异常、容器泄漏或标签缺失时隔离并启动偏差处理。

## 5. 关键控制与放行

- [ ] 标签和批次保持一致
- [ ] 危险品不得与不相容物混放
- [ ] 样品移交必须留痕
- [ ] 实际记录已由经授权人员复核，相关异常、偏差及变更均有处置结论。
- [ ] 涉及定量阈值、保存时限或安全联锁时，只引用已批准的内部标准，禁止根据本示例自行推定。

## 6. 异常及安全要求

出现危及人员安全、设备完整性或数据可信度的情形，应立即停止相关操作并执行经批准的现场应急或隔离程序，报告授权责任人；不得绕过防护措施、擅自恢复运行或删除异常记录。按 SOP-006 和 SOP-016 处理调查与整改。

## 7. 配套记录与关联文件

- 记录表单：FM-005、FM-018（详见 `forms/` 目录；具体字段可按受控场景扩展）。
- 通用关联：SOP-004 实验记录与数据管理、SOP-018 文件与记录控制、SOP-020 变更管理。
- 记录应保持真实、完整、可追溯，不在公开仓库录入实际生产或研发数据。

- [ ] 留样量

- [ ] 处置责任人

- [ ] 实际启用日期、适用岗位、培训与版本控制经正式批准。
