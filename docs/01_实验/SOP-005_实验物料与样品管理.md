# SOP-005 实验物料与样品管理

> **公开草案 V0.2｜未审核、未批准、不得直接作为现场作业依据。**
> 本文件为脱敏的通用管理模板。所有专有配方、设备操作边界、危险化学品细节、人员与原始数据应另存于受控内部系统。

## 1. 目的与范围

实现物料从领用到退库以及样品从采集到处置的全链条管理。适用于经组织授权、符合现行法律法规和设备制造商要求的相关实验室活动；不替代具体工艺卡、设备说明书、SDS 与应急预案。

## 2. 角色与职责

物料管理员、实验操作人、检测接收人按岗位授权和职责分离原则分工；实际操作者填写原始记录，复核或审批人员独立签署。组织未确定的岗位由内部文件另行指定，公开文件不含个人名单。

## 3. 作业前提

- 已取得适用的受控方案、工艺卡或检验方法版本，并确认当前有效。
- 人员能力、场所安全、仪器状态、原辅材料和必要的应急资源符合要求。
- 核查批次、设备、样品及记录编号对应关系；发现不明确事项时暂停开展相关步骤。

## 4. 标准程序

1. 新物料入库登记名称、来源、批次、数量、危害属性、储存条件和有效期，关联适用的安全资料。
2. 按相容性和储存条件分区，关键易变质物料设置监测与超期处置流程。
3. 领料时按批准清单核对物料标识、批次、有效状态和数量，记录领取与归还。
4. 取样后以唯一编号标识样品来源、采集时间、保存条件、危害警示与用途。
5. 样品在实验组、检测组及外协方之间移交时记录交接人、时间、容器状态和数量。
6. 按批准留样方案执行保留、复测、销毁与空容器处置，禁止丢弃未识别样品。
7. 盘点异常、容器泄漏或标签缺失时隔离并启动偏差处理。

## 5. 关键控制与放行

- [ ] 标签和批次保持一致
- [ ] 危险品不得与不相容物混放
- [ ] 样品移交必须留痕
- [ ] 实际记录已由经授权人员复核，相关异常、偏差及变更均有处置结论。
- [ ] 涉及定量阈值、保存时限或安全联锁时，只引用已批准的内部标准，禁止根据本示例自行推定。

## 6. 异常及安全要求

出现危及人员安全、设备完整性或数据可信度的情形，应立即停止相关操作并执行经批准的现场应急或隔离程序，报告授权责任人；不得绕过防护措施、擅自恢复运行或删除异常记录。按 SOP-006 和 SOP-016 处理调查与整改。

## 7. 配套记录与关联文件

- 记录表单：FM-005、FM-018（详见 `forms/` 目录；具体字段可按受控场景扩展）。
- 通用关联：SOP-004 实验记录与数据管理、SOP-018 文件与记录控制、SOP-020 变更管理。
- 记录应保持真实、完整、可追溯，不在公开仓库录入实际生产或研发数据。

## 8. 送审前待确认事项

- [ ] 保质期判定
- [ ] 留样量
- [ ] 库位规则
- [ ] 处置责任人
- [ ] 技术负责人、安全负责人和文件批准人确认适用性、法律法规与设备制造商要求。
- [ ] 实际启用日期、适用岗位、培训与版本控制经正式批准。

## 8. 可执行分步检查（结合公开实验室管理经验补充）

本节是管理层面的示例流程，需按现场设备和人员授权制定内部版，不提供未验证的化学操作数值。

| 关口 | 执行要点 | 通过或输出证据 | 不满足时 |
| --- | --- | --- | --- |
| 入库登记 | 核对包装完整、供应商标签、批次、浓度或规格、有效期和SDS | 物料可唯一识别且标签信息一致 | 隔离缺签或泄漏物料 |
| 储位分配 | 根据危害类别、相容性、温控、通风、二次容纳和访问权限分区 | 储位与危险特性匹配，限制高危存放 | 不得简单按字母顺序混放 |
| 库存复查 | 记录容器状态、有效期、必要储存环境和异常色泽或析出迹象 | 风险物料状态可判断；到期物料受控 | 不确定时停止使用并请专业人员评估 |
| 领用复核 | 按批准物料清单核对品种、批号、余量及使用人授权 | 出入库数量可追溯 | 退回未授权领用 |
| 样品编号 | 采样时关联实验编号、工序、时间、危险提示、保存条件和目的 | 包装与标签可在交接中独立识别 | 标签不足退回补充，不猜测内容 |
| 样品流转 | 交出/接收双方核对数量、包装、保存要求和到达时间 | 形成连续流转记录 | 差异立即隔离并登记偏差 |
| 退库/销毁 | 对剩余物、污染包装和留样按相关法规及内部标准判定 | 退库/危险废弃物转移有记录 | 禁入下水道或普通垃圾 |

## 9. 原始记录最小字段与证据链

- [ ] 物料唯一标识、批次、储存区位、有效期
- [ ] 领料订单、实领实退数量与复核
- [ ] 样品编号、来源、容器、保存条件
- [ ] 每次交接签收、异常与留样处置
- [ ] 库存盘点差异及处理决定

记录必须能串联：任务或实验编号 → 样品／设备／物料 → 方法及原始数据 → 质量复核 → 偏差及最终结论。所有实际标识与数据仅在内部受控系统填写。

## 10. 典型错漏与复核要点

- **关注：**试剂与产物标签不得只写内部昵称。
- **关注：**有危害物料的必要安全信息不得为保密而隐去。
- **关注：**样品不明时不得直接测试或处置。

**复核关口：** 对本SOP每一项关键控制，应有核验依据、记录位置、核验角色及发现问题后的处置；没有依据的定量限值不得从其他实验室直接移植。
