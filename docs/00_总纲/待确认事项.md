## 送审闸门

- [ ] 对照制造商资料、法规、SDS 及风险评估批准设备和操作限值。
- [ ] 明确上报权限、记录保存、样品流转和废弃物处置的责任。
- [ ] 完成必要的培训、试运行验证、应急演练与审核签字。
- [ ] 对所有 `【待确认】`、`【待填】` 字段完成受控核实。
- [ ] **只有内部正式批准后才可用于实际实验，公开示例绝不视为批准。**
