# 外部实验室经验对标与引用来源

> 编写时间：2026-11-09｜资料来源：公开官方机构页面｜用途：供 SOP 草案设计参考，**不代表已按相关标准完成审核、认可或认证。**

## 1. 他人实践中可借鉴的共同结构

国内外公开资料反复出现以下要素：

1. **以任务为中心**：明确目的、适用范围、负责人、准备条件、操作步骤和结束/验收条件。
2. **先评估风险再启动**：识别物料、能量、设备、人员暴露和废弃物等危险源，并明确事前批准情形。
3. **按任务风险落实培训**：阅读文件不是能力证明，关键任务要经过现场演示、实操评估和授权。
4. **让结果可追溯**：样品编号、设备、方法、人员、时间、原始数据、偏差和审核组成完整证据链。
5. **把异常纳入流程**：不合格不直接忽略；有停用、隔离、再检查、纠正预防及重新批准机制。
6. **把运行数据与公开模板分开**：工艺配方、产品判定指标、原始数据、员工信息存放于内部受控系统。

## 4. 采用前需要进行的内部审查

- 技术审查：确认流程适用于本实验室研究对象、样品类型、设备和检测目标。
- 安全与职业卫生审查：确认风险评估、通风防护、应急措施和高温高压系统的制造商设计界限。
- 质量审查：确认记录字段、方法验证、判定规则及数据保存逻辑。
- 法规审查：识别中国企业实验室适用的法律法规、地方规定和危险废物管理要求；不把美国/高校文件自动视为本单位法定义务。
- 文件审批：由授权人员在内部受控系统确定签字权限、编号、生效日期和保密级别。
