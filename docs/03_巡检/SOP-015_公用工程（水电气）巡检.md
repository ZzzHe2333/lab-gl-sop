# SOP-015 公用工程（水电气）巡检

> **公开草案 V0.2｜未审核、未批准、不得直接作为现场作业依据。**
> 本文件为脱敏的通用管理模板。所有专有配方、设备操作边界、危险化学品细节、人员与原始数据应另存于受控内部系统。

## 1. 目的与范围

保障实验供水、供电、供气及配套设施运行受控。适用于经组织授权、符合现行法律法规和设备制造商要求的相关实验室活动；不替代具体工艺卡、设备说明书、SDS 与应急预案。

## 2. 角色与职责

公用工程负责人、设备使用人、值班人员按岗位授权和职责分离原则分工；实际操作者填写原始记录，复核或审批人员独立签署。组织未确定的岗位由内部文件另行指定，公开文件不含个人名单。

## 3. 作业前提

- 已取得适用的受控方案、工艺卡或检验方法版本，并确认当前有效。
- 人员能力、场所安全、仪器状态、原辅材料和必要的应急资源符合要求。
- 核查批次、设备、样品及记录编号对应关系；发现不明确事项时暂停开展相关步骤。

## 4. 标准程序

1. 核对公用工程设施清单、供给范围和安全隔离点。
2. 检查水路压力、泄漏、排水、循环及必要的水质状态。
3. 检查配电箱、接地、保护装置、线缆温升与违规临时接线。
4. 检查气源标识、固定、阀门、压力表、减压器和泄漏迹象。
5. 对会影响反应安全的供给异常，按设备批准停机程序实施保护。
6. 记录检修通知、停供事件、恢复检查与影响评估；外协施工需明确许可与监护。

## 5. 关键控制与放行

- [ ] 不得擅自调整供气压力边界
- [ ] 停供与复供须评估工艺影响
- [ ] 涉及电气应由授权人员检修
- [ ] 实际记录已由经授权人员复核，相关异常、偏差及变更均有处置结论。
- [ ] 涉及定量阈值、保存时限或安全联锁时，只引用已批准的内部标准，禁止根据本示例自行推定。

## 6. 异常及安全要求

出现危及人员安全、设备完整性或数据可信度的情形，应立即停止相关操作并执行经批准的现场应急或隔离程序，报告授权责任人；不得绕过防护措施、擅自恢复运行或删除异常记录。按 SOP-006 和 SOP-016 处理调查与整改。

## 8. 可执行分步检查（参考公开实验室管理经验）

下表为流程检查模板。所有具体容差、安全阈值、计量标准、周期与法定要求必须由适用的受控资料确认。

| 关口 | 执行要点 | 通过或输出证据 | 不满足时 |
| --- | --- | --- | --- |
| 系统识别 | 登记供水、配电、供气、循环和相应隔离点 | 图纸与设备标记对应 | 不明阀位不得尝试 |
| 水冷回路 | 检查泄漏、泵、回水、冷却能力和介质状态 | 满足批准设备条件 | 冷却丢失按停机预案 |
| 供电检查 | 观察保护装置、异常热、破损线缆与接地状态 | 无明显安全缺陷 | 电气检修交授权人员 |
| 气路检查 | 核对气源名称、固定、减压装置和泄漏核查 | 供气符合适用设备要求 | 泄漏进入应急处置 |
| 停供评估 | 评估反应和测量对断电、失气、停水的风险 | 有保安全措施与关键设备列表 | 风险未受控不得开机 |
| 复供恢复 | 确认故障解除、仪表状态和受影响试验处置 | 经授权依启动程序恢复 | 不自动恢复实验 |

## 9. 原始记录的最小证据链

- [ ] 公用工程台账及点位图
- [ ] 巡检读数、报警及异常时间
- [ ] 停供影响、隔离、维修记录
- [ ] 复供批准和运行确认

每项任务应能串联：任务与版本 → 责任岗位和设备 → 判断依据 → 实际记录 → 异常处置 → 独立复核 → 放行或关闭。只在授权的内部系统填写真实数据。

## 10. 常见错漏及审核关注点

- **检查：**气体设备边界不能推测。
- **检查：**恢复供应不等于自动可运行。
- **检查：**带电维修需资格和作业控制。

**复核要求：** 不能把其他实验室的设备边界、药品参数或审批周期直接视为本实验室有效标准；每个审核结果均应有记录位置和处置授权。
