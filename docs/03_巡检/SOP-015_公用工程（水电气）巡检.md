# SOP-015 公用工程（水电气）巡检

> **公开草案 V0.1｜未审核、未批准、不得直接作为现场作业依据。**
> 本文件为脱敏的通用管理模板。所有专有配方、设备操作边界、危险化学品细节、人员与原始数据应另存于受控内部系统。

## 1. 目的与范围

保障实验供水、供电、供气及配套设施运行受控。适用于经组织授权、符合现行法律法规和设备制造商要求的相关实验室活动；不替代具体工艺卡、设备说明书、SDS 与应急预案。

## 2. 角色与职责

公用工程负责人、设备使用人、值班人员按岗位授权和职责分离原则分工；实际操作者填写原始记录，复核或审批人员独立签署。组织未确定的岗位由内部文件另行指定，公开文件不含个人名单。

## 3. 作业前提

- 已取得适用的受控方案、工艺卡或检验方法版本，并确认当前有效。
- 人员能力、场所安全、仪器状态、原辅材料和必要的应急资源符合要求。
- 核查批次、设备、样品及记录编号对应关系；发现不明确事项时暂停开展相关步骤。

## 4. 标准程序

1. 核对公用工程设施清单、供给范围和安全隔离点。
2. 检查水路压力、泄漏、排水、循环及必要的水质状态。
3. 检查配电箱、接地、保护装置、线缆温升与违规临时接线。
4. 检查气源标识、固定、阀门、压力表、减压器和泄漏迹象。
5. 对会影响反应安全的供给异常，按设备批准停机程序实施保护。
6. 记录检修通知、停供事件、恢复检查与影响评估；外协施工需明确许可与监护。

## 5. 关键控制与放行

- [ ] 不得擅自调整供气压力边界
- [ ] 停供与复供须评估工艺影响
- [ ] 涉及电气应由授权人员检修
- [ ] 实际记录已由经授权人员复核，相关异常、偏差及变更均有处置结论。
- [ ] 涉及定量阈值、保存时限或安全联锁时，只引用已批准的内部标准，禁止根据本示例自行推定。

## 6. 异常及安全要求

出现危及人员安全、设备完整性或数据可信度的情形，应立即停止相关操作并执行经批准的现场应急或隔离程序，报告授权责任人；不得绕过防护措施、擅自恢复运行或删除异常记录。按 SOP-006 和 SOP-016 处理调查与整改。

## 7. 配套记录与关联文件

- 记录表单：FM-011（详见 `forms/` 目录；具体字段可按受控场景扩展）。
