# SOP-016 隐患整改闭环

> **公开草案 V0.2｜未审核、未批准、不得直接作为现场作业依据。**
> 本文件为脱敏的通用管理模板。所有专有配方、设备操作边界、危险化学品细节、人员与原始数据应另存于受控内部系统。

## 1. 目的与范围

确保发现的安全与质量隐患均有责任、期限和验证。适用于经组织授权、符合现行法律法规和设备制造商要求的相关实验室活动；不替代具体工艺卡、设备说明书、SDS 与应急预案。

## 2. 角色与职责

发现人、整改责任人、复核人、管理审批人按岗位授权和职责分离原则分工；实际操作者填写原始记录，复核或审批人员独立签署。组织未确定的岗位由内部文件另行指定，公开文件不含个人名单。

## 3. 作业前提

- 已取得适用的受控方案、工艺卡或检验方法版本，并确认当前有效。
- 人员能力、场所安全、仪器状态、原辅材料和必要的应急资源符合要求。
- 核查批次、设备、样品及记录编号对应关系；发现不明确事项时暂停开展相关步骤。

## 4. 标准程序

1. 登记隐患描述、现场证据、位置、首次发现时间和关联设备。
2. 按风险严重程度评估是否需立即隔离、停机或启动应急响应。
3. 指定整改责任和计划完成日期，对延误原因实施升级处理。
4. 执行纠正措施时保留照片、维修报告、检测记录或培训证据。
5. 由独立复核人检查整改结果与剩余风险，无法确认有效不得关闭。
6. 对重复隐患进行趋势分析，提出系统性预防措施并更新相关 SOP。

## 5. 关键控制与放行

- [ ] 停机隐患未经验证不得复用
- [ ] 延期必须有审批与临时风险措施
- [ ] 整改关闭要有证据
- [ ] 实际记录已由经授权人员复核，相关异常、偏差及变更均有处置结论。
- [ ] 涉及定量阈值、保存时限或安全联锁时，只引用已批准的内部标准，禁止根据本示例自行推定。

## 6. 异常及安全要求

出现危及人员安全、设备完整性或数据可信度的情形，应立即停止相关操作并执行经批准的现场应急或隔离程序，报告授权责任人；不得绕过防护措施、擅自恢复运行或删除异常记录。按 SOP-006 和 SOP-016 处理调查与整改。

## 7. 配套记录与关联文件

- 记录表单：FM-012（详见 `forms/` 目录；具体字段可按受控场景扩展）。
- 通用关联：SOP-004 实验记录与数据管理、SOP-018 文件与记录控制、SOP-020 变更管理。
- 记录应保持真实、完整、可追溯，不在公开仓库录入实际生产或研发数据。

## 8. 送审前待确认事项

- [ ] 隐患分级规则
- [ ] 整改时限
- [ ] 升级权限
- [ ] 技术负责人、安全负责人和文件批准人确认适用性、法律法规与设备制造商要求。
- [ ] 实际启用日期、适用岗位、培训与版本控制经正式批准。

## 8. 可执行分步检查（参考公开实验室管理经验）

下表为流程检查模板。所有具体容差、安全阈值、计量标准、周期与法定要求必须由适用的受控资料确认。

| 关口 | 执行要点 | 通过或输出证据 | 不满足时 |
| --- | --- | --- | --- |
| 隐患受理 | 登记地点、时间、对象、事实与照片编号 | 每条问题有唯一编号 | 拒绝口头代替记录 |
| 风险分级 | 按批准的分级方法判断暴露、严重度与是否立即隔离 | 有判定依据及责任人 | 重大隐患先停机再评估 |
| 临时控制 | 选择隔离、停用、现场告知或临时监测 | 措施可观察且有效 | 控制失败升级 |
| 整改方案 | 确定根因、措施、负责人、资源、期限和验收方式 | 措施与原因直接对应 | 退回无证据标准的方案 |
| 执行追踪 | 保存工单、采购、维保、培训或照片等证据 | 有完成时间及新风险评估 | 异常重新立项 |
| 独立复核 | 确认整改有效并检查重复风险 | 验收人签署并关闭 | 不达标继续隔离 |
| 趋势改进 | 汇总复发隐患并推动制度修订 | 行动落实到新版本与培训 | 上报管理评审 |

## 9. 原始记录的最小证据链

- [ ] 隐患编号、对象、影像证据
- [ ] 风险等级与临时控制
- [ ] 整改责任、期限及证据
- [ ] 独立验证、重开或关闭

每项任务应能串联：任务与版本 → 责任岗位和设备 → 判断依据 → 实际记录 → 异常处置 → 独立复核 → 放行或关闭。只在授权的内部系统填写真实数据。

## 10. 常见错漏及审核关注点

- **检查：**做了整改不等于已验证。
- **检查：**重大风险宜先隔离。
- **检查：**延期关闭须记录剩余风险。

**复核要求：** 不能把其他实验室的设备边界、药品参数或审批周期直接视为本实验室有效标准；每个审核结果均应有记录位置和处置授权。
