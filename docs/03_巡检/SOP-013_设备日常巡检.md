# SOP-013 设备日常巡检

> **公开草案 V0.1｜未审核、未批准、不得直接作为现场作业依据。**
> 本文件为脱敏的通用管理模板。所有专有配方、设备操作边界、危险化学品细节、人员与原始数据应另存于受控内部系统。

## 1. 目的与范围

在开工前和运行过程中识别设备可见异常。适用于经组织授权、符合现行法律法规和设备制造商要求的相关实验室活动；不替代具体工艺卡、设备说明书、SDS 与应急预案。

## 2. 角色与职责

设备使用人、值班人员、设备管理员按岗位授权和职责分离原则分工；实际操作者填写原始记录，复核或审批人员独立签署。组织未确定的岗位由内部文件另行指定，公开文件不含个人名单。

## 3. 作业前提

- 已取得适用的受控方案、工艺卡或检验方法版本，并确认当前有效。
- 人员能力、场所安全、仪器状态、原辅材料和必要的应急资源符合要求。
- 核查批次、设备、样品及记录编号对应关系；发现不明确事项时暂停开展相关步骤。

## 4. 标准程序

1. 核对设备状态标牌、清洁度、紧固件、防护罩和周围安全通道。
2. 检查仪表显示、报警、联锁、阀门、管路、泄漏及异常噪声。
3. 运行中按现场批准的频次记录关键设备参数与异常趋势。
4. 检查清洁、冷却、通风、电源等配套系统是否处于允许状态。
5. 异常项目标识并立即采取隔离、停机或报修措施，不得自行屏蔽保护装置。
6. 完成交接签字，重大问题转入设备维修或隐患整改闭环。

## 5. 关键控制与放行

- [ ] 有异常不得直接勾选合格
- [ ] 巡检记录与维修工单关联
- [ ] 报警或联锁异常优先处置
- [ ] 实际记录已由经授权人员复核，相关异常、偏差及变更均有处置结论。
- [ ] 涉及定量阈值、保存时限或安全联锁时，只引用已批准的内部标准，禁止根据本示例自行推定。

## 6. 异常及安全要求

出现危及人员安全、设备完整性或数据可信度的情形，应立即停止相关操作并执行经批准的现场应急或隔离程序，报告授权责任人；不得绕过防护措施、擅自恢复运行或删除异常记录。按 SOP-006 和 SOP-016 处理调查与整改。

## 7. 配套记录与关联文件

- 记录表单：FM-011（详见 `forms/` 目录；具体字段可按受控场景扩展）。
- 通用关联：SOP-004 实验记录与数据管理、SOP-018 文件与记录控制、SOP-020 变更管理。
- 记录应保持真实、完整、可追溯，不在公开仓库录入实际生产或研发数据。
