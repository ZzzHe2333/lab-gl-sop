# SOP-014 现场安全与5S巡检

> **公开草案 V0.2｜未审核、未批准、不得直接作为现场作业依据。**
> 本文件为脱敏的通用管理模板。所有专有配方、设备操作边界、危险化学品细节、人员与原始数据应另存于受控内部系统。

## 1. 目的与范围

保持实验场所安全、整洁及危险源可控。适用于经组织授权、符合现行法律法规和设备制造商要求的相关实验室活动；不替代具体工艺卡、设备说明书、SDS 与应急预案。

## 2. 角色与职责

现场负责人、各区域使用人、安全管理人员按岗位授权和职责分离原则分工；实际操作者填写原始记录，复核或审批人员独立签署。组织未确定的岗位由内部文件另行指定，公开文件不含个人名单。

## 3. 作业前提

- 已取得适用的受控方案、工艺卡或检验方法版本，并确认当前有效。
- 人员能力、场所安全、仪器状态、原辅材料和必要的应急资源符合要求。
- 核查批次、设备、样品及记录编号对应关系；发现不明确事项时暂停开展相关步骤。

## 4. 标准程序

1. 按区域检查整理、整顿、清扫、清洁与素养执行情况。
2. 核对通风、防护装备、应急器材、洗眼装置及安全出口可用状态。
3. 确认化学品标签清晰、不相容物分区、废物容器封闭且标识正确。
4. 检查用电、气瓶固定、加热设备周边、防滑与泄漏管理。
5. 发现隐患立即分级处置并记录责任、期限和复核证据。
6. 按周期回顾重复隐患，必要时更新布置、培训或工艺要求。

## 5. 关键控制与放行

- [ ] 堵塞应急出口须立即纠正
- [ ] 危险废物不得与生活垃圾混放
- [ ] 巡检不是替代专业安全检查
- [ ] 实际记录已由经授权人员复核，相关异常、偏差及变更均有处置结论。
- [ ] 涉及定量阈值、保存时限或安全联锁时，只引用已批准的内部标准，禁止根据本示例自行推定。

## 6. 异常及安全要求

出现危及人员安全、设备完整性或数据可信度的情形，应立即停止相关操作并执行经批准的现场应急或隔离程序，报告授权责任人；不得绕过防护措施、擅自恢复运行或删除异常记录。按 SOP-006 和 SOP-016 处理调查与整改。

- [ ] 实际启用日期、适用岗位、培训与版本控制经正式批准。

## 8. 可执行分步检查（参考公开实验室管理经验）

下表为流程检查模板。所有具体容差、安全阈值、计量标准、周期与法定要求必须由适用的受控资料确认。

| 关口 | 执行要点 | 通过或输出证据 | 不满足时 |
| --- | --- | --- | --- |
| 区域划分 | 界定配料区、设备区、样品区、废物区、通道及责任岗位 | 职责明确 | 无人管理区域补充责任 |
| 整理清洁 | 去除不明容器、绊倒物、污染工具及闲置可燃品 | 通道畅通且标识清晰 | 当场隔离障碍 |
| 危化品检查 | 核对标签、SDS、相容分区、容器完好和二次盛装 | 相容性与储存条件正确 | 不明物料隔离 |
| 应急装备 | 检查洗眼、通风、消防、吸附设施和PPE状态 | 有效且取用不受阻 | 相关危险操作暂停 |
| 电气气瓶 | 核对接线、线缆、气瓶固定、热源和泄漏迹象 | 风险处于批准控制条件 | 安排专业处置 |
| 危废巡查 | 核对类别、封口、标签、暂存容器和合规路径 | 满足适用环保要求 | 禁止未经许可排放 |
| 问题闭环 | 记录证据、风险、整改、复查和重复问题 | 有独立关闭结论 | 未证实有效不关闭 |

## 9. 原始记录的最小证据链

- [ ] 巡检区域、岗位、时间
- [ ] 危害类别及证据照片索引
- [ ] 异常项风险级别及隔离
- [ ] 整改验收和回查

每项任务应能串联：任务与版本 → 责任岗位和设备 → 判断依据 → 实际记录 → 异常处置 → 独立复核 → 放行或关闭。只在授权的内部系统填写真实数据。

## 10. 常见错漏及审核关注点

- **检查：**5S整洁不等同于化学安全。
- **检查：**应急设施不得被遮挡。
- **检查：**危废贮存要求按当地适用法规核定。

**复核要求：** 不能把其他实验室的设备边界、药品参数或审批周期直接视为本实验室有效标准；每个审核结果均应有记录位置和处置授权。
