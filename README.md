# 实验室标准作业程序（SOP）文件目录

本目录收录研发实验室作业、检验检测、现场巡检、设备维护和文件管理相关的标准作业程序及配套记录表。

**文件状态：全部 SOP 和记录表尚未完成本单位正式审批。** 具体工艺条件、设备运行边界、危险化学品处置和人员授权须执行有效受控文件、设备说明书及适用法规。未经批准不得作为现场作业依据。

## 文件目录

- `docs/01_实验/` — 实验立项、小试、中试、数据、物料与异常管理
- `docs/02_检测/` — 来料、中控、成品、外协、计量与试剂管理
- `docs/03_巡检/` — 设备、现场、公用工程与隐患闭环
- `docs/04_设备与安全/` — 设备维修保养
- `docs/05_支撑/` — 文件、培训与变更控制
- `docs/00_总纲/` — 文件台账、发布前待确认清单与模板说明
- `forms/` — 18 份 Markdown 空白记录表

## 文件状态与管理要求

- SOP-002《小试实验操作》为根据原始 DOCX 转写的 V0.14 草案，包含原件中标注的内部信息；应由文件责任人核定其公开权限。
- SOP-001、SOP-003～020 为 V0.4 草案；配套 FM-001～018 为未批准的空白记录表。
- 文件编号、结构、审批要求及修订控制依据 [SOP 统一编写规范](docs/00_总纲/SOP统一编写规范.md) 执行。
- 文件版本、待确认事项及适用范围以 [文件台账](docs/00_总纲/文件台账.md) 和有效内部审批记录为准。

## 如何使用

1. 从对应 SOP 文件建立 **内部受控副本**，核对适用设备、场所、工艺和组织职责。
2. 在内部系统填充工艺参数卡、检查阈值、具体岗位、审批签名、应急响应及记录保存规则；不要在公开仓库添加这些数据。
3. 完成技术、安全和授权管理审核后，按组织文件控制规则发布正式版本。
4. 原始实验记录、检测数据和真实样品台账仅存于受控业务系统，不在 GitHub 提交。

## 安全与隐私

**禁止提交**真实配方及物料代号、实验批号、工艺参数、技术诀窍、未公开检测结果、商业合同、设备序列号、个人姓名与联系方式、内部文件扫描件、密钥及访问令牌。参见 [SECURITY.md](SECURITY.md)、[CONTRIBUTING.md](CONTRIBUTING.md) 和 [待确认事项](docs/00_总纲/待确认事项.md)。

本仓库文件尚未经特定设备及现场适用性验证。公开文档的使用和再分发应符合现有 GPL-3.0 许可证及相关保密、知识产权和个人信息保护义务。
